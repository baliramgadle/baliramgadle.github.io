# Baliram Gadle — AI Engineer Portfolio

React + TypeScript + Vite + Tailwind CSS + Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Data-driven structure

All portfolio content is intentionally separated into JSON files:

- `src/data/site.json`
- `src/data/skills.json`
- `src/data/experience.json`
- `src/data/projects.json`
- `src/data/achievements.json`
- `src/data/certifications.json`
- `src/data/education.json`
- `src/data/navigation.json`

Images are under:

`public/assets/images/`

Replace the placeholder certificate images with the actual certificate scans/screenshots when ready.

## Important

The portfolio intentionally contains no Java-focused content. It is positioned around AI Engineering, Generative AI, Agentic AI, RAG, Python, full-stack AI and enterprise AI systems.

Professional/confidential work is described at a high level and should not be expanded with internal details unless those details are approved for public disclosure.
